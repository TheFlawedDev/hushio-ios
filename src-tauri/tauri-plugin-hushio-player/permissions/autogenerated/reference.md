## Default Permission

Playback commands, queue sync and events for the Android player

#### This default permission set includes the following:

- `allow-player-set-queue`
- `allow-player-append`
- `allow-player-insert-next`
- `allow-player-remove-at`
- `allow-player-move`
- `allow-player-play`
- `allow-player-pause`
- `allow-player-toggle`
- `allow-player-next`
- `allow-player-previous`
- `allow-player-seek`
- `allow-player-set-speed`
- `allow-player-set-volume`
- `allow-player-set-repeat`
- `allow-player-set-shuffle`
- `allow-player-set-skip-silence`
- `allow-player-set-eq`
- `allow-player-set-sleep-timer`
- `allow-player-set-url`
- `allow-player-set-like`
- `allow-player-get-state`
- `allow-player-get-insets`
- `allow-player-exit`
- `allow-player-haptic-tick`
- `allow-player-keep-awake`
- `allow-player-set-system-bars`
- `allow-player-take-launch`
- `allow-cast-open`
- `allow-cast-load`
- `allow-cast-play-pause`
- `allow-cast-seek`
- `allow-cast-status`
- `allow-cast-stop`
- `allow-registerListener`
- `allow-removeListener`
